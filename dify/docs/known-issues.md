# 已知问题与取舍

> 面向评审：这里集中列"作品有意为之的选择"与"尚未解决的问题"，避免在 README 里散落遗漏。
> 每条都写：现象 → 原因 → 影响 → 缓解方式。

## 1. 前端跑的是 dev 模式，不是生产构建

- **现象**：首屏 60–100 秒，之后正常；页面挂着一个开发态浮层（截图脚本会隐藏）。
- **原因**：本机 8GB 内存，`next build` 实测峰值 RSS 5.5GB，被内核 OOM 杀掉（`evidence/logs` 外的系统日志有记录）。
- **影响**：只影响首屏速度，功能与生产构建一致。
- **缓解**：≥16GB 机器执行 `cd web && pnpm build && pnpm start` 即可，DSL 无需改动。

## 2. DSL 里没有 Code 节点

- **现象**：19 个节点中没有 code 节点。
- **原因**：`dify-sandbox` 需要 chroot + seccomp，非 root 环境起不来。
- **影响**：无法用 Python/JS 做 JSON 解析或数值计算。
- **缓解**：判定改用「参数提取器」节点；分支用「IF/ELSE」；需要结构化数据时由后端返回 `KEY=VALUE` 文本块（见 `docs/design.md` §4）。

## 3. Embedding 是哈希向量，不是语义模型

- **现象**：`EMBEDDING_MODE=hash`，1024 维字符 n-gram 向量。
- **原因**：要保证评审无需作者本地服务即可复现；运行环境无 GPU。
- **影响**：只对短句有效，长段落或纯同义改写（不含共同字符）可能匹配不到。
- **缓解**：`EMBEDDING_MODE=api` 可接任意 OpenAI 兼容 embedding，需同步改 `VECTOR(1024)` 维度并重建表。

## 4. 档位（tier）映射在后端，不在 Dify

- **现象**：`grudge → 0..4` 的映射写在 `backend/app/rules.py`，Dify 只按 `TIER=n` 分支。
- **原因**：Dify 的 HTTP 节点只能拿到响应文本，没有 JSON/数值解析节点；把映射放后端可省一次 LLM 调用。
- **影响**：严格说"档位判定"不在编排层内；但**分支决策**（逐客/闲聊/打烊/常规）都在 Dify。
- **缓解**：若要完全在 Dify 判定，可改用参数提取器抽出 `grudge` 数值再逐档比较（多一次 LLM 调用）。

## 5. inn-api 是单机 demo，没有鉴权

- **现象**：`GET /inn/session`、`POST /inn/ledger` 无需 token；单 uvicorn 进程。
- **原因**：赛题演示场景，评审本机运行。
- **影响**：不能直接暴露公网；并发高时无横向扩展。
- **缓解**：README §7 已声明；生产化需要加网关鉴权与连接池/多 worker（pymysql 连接已按请求创建，可平滑扩）。

## 6. 账本（seekdb）与记忆（PowerContext）是两套存储

- **现象**：只跑 `db/init.sh` 不会清 PowerContext 记忆，可能出现"账本 62、记忆里 92"。
- **原因**：有意分离——事件事实与人物印象不同生命周期。
- **影响**：重置演示数据时要两边一起清。
- **缓解**：用 `tools/reset-demo.sh`（重建 seekdb + 清空 PC 记忆并重启）。

## 7. seekdb 作 Dify 元数据库：只做了可行性实测，未纳入主线

- **现象**：`DB_TYPE=seekdb` 下 143 张表迁移成功、实例可启动（`evidence/logs/dify-on-seekdb.md`）。
- **原因**：主线选 MySQL 是为复现更稳（Dify 官方默认路径）。
- **影响**：README §7.1 如实声明"未纳入本提交的验证范围"。
- **缓解**：`tools/verify-seekdb-meta.sh` 可随时复跑该验证。

## 8. 依赖不可用时的兜底话术是固定的

- **现象**：seekdb/inn-api 挂掉时，回答固定为"账本让雨打湿了……"。
- **原因**：兜底走 Answer 节点，不调用 LLM。
- **影响**：连续多轮故障会重复同一句话（真实日志见 S7）。
- **缓解**：可给兜底节点加 2–3 条轮换文案（未做，属于锦上添花）。

## 9. 本机环境坑（不是作品缺陷，但复现时可能遇到）

| 坑 | 说明 |
| --- | --- |
| 2881 端口被占 | 本机有其它 seekdb 实例，本项目统一用 2891 |
| `DROP DATABASE` 卡住 | OceanBase 异步回收，会阻塞后续 DDL；验证脚本因此每次用唯一库名 |
| 看门狗 flock 被继承 | 已修：子进程启动加 `9>&-` |
| Dify 令牌 60 分钟过期 | 已修：`tools/dify-login.sh` + 自检遇 401 自动重登 |

详细处理办法见 `docs/operator-notes.md`。
