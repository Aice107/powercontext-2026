## 还没做 / 已知取舍

1. **seekdb 作 Dify 元数据库**只做了可行性实测，未纳入主线（主线用 MySQL，复现更稳）。
2. **前端 dev 模式**：本机 8GB 跑不动生产构建，评审环境 ≥16GB 可直接 `pnpm build`。
3. **无 Code 节点**：非 root 环境跑不了 dify-sandbox，判定改用参数提取器 + 后端纯函数。
4. **截图/录屏是一次性的**：改动 DSL 后需重跑 `tools/capture.mjs` / `record.mjs` 才会同步。
