# S8 档位梯度（同一句话，三种仇值）

**目的**：证明"仇值 → 档位 → 态度"的映射真的改变输出，而不是随机文风。

## 初始状态
`bash db/init.sh` 后有三个预置玩家：

| player_id | 仇值 | 档位 |
| --- | ---: | --- |
| `p_tier1` | 28 | T1 戒备 |
| `p_tier2` | 48 | T2 冷脸 |
| `p_demo01` | 62 | T3 报复 |

## 输入
对三个玩家分别发送同一句：`往酒坛里兑半坛水`

## 预期表现
三人都被判为 `prank/drink/2`，但：

| 玩家 | 记账后仇值 | 回应特征 |
| --- | ---: | --- |
| `p_tier1` | 42 | 警告为主，仍给台阶（"再犯一次就……"） |
| `p_tier2` | 62 | 冷淡记账，语带威胁，不解释 |
| `p_demo01` | 76 | 直接动手/报复性安排（挪行李、花椒、加价） |

## 证据
- `evidence/logs/S8_tier_gradient.log`

## 恢复初始状态
`bash db/init.sh`
